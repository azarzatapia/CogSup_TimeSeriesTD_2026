## Overview

This repository contains the practical session (TD - _Travaux Dirigés_) materials for the **Time Series Analysis** module in the Cognitive Science Master's program (CogSup 2026).

In this session, you will learn to process and analyze EEG time-series data using Python and the `mne` package.

### How to use:

1. Click the **Open in Colab** badge above to launch the notebook.
2. Immediately go to **File > Save a copy in Drive** to create your own working copy.
3. Execute the setup cell at the top of the notebook to automatically download the sample datasets and install required packages.
